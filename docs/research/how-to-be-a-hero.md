# How to be a Hero (HtbaH) + weitere Systeme

**Autor:** Sebastian Wenzel — frei verfügbar als Wiki/PDF (CC-lizenziert).

## Charakterbogen-Felder

**Stammdaten:** Name, Geschlecht, Alter, Statur, Aussehen, Beruf/Hobbys, Charakterzüge, Stimme, Kleidung, Vorlieben, Vor-/Nachteile.

**Begabungen (3):** Handeln (körperlich), Wissen (intellektuell), Soziales (zwischenmenschlich). Werte 0–100 (W100-Skala).

**Fähigkeiten (Skills) — frei wählbar:** Spieler verteilen Punkte und benennen Skills selbst (z.B. "Schlösser knacken", "Astronomie"). Jeder Skill ist einer Begabung zugeordnet. Punktepool typ. **300 Punkte** (Stufenaufstieg) bzw. 350–400 (One-Shot). Skill-Cap stufen-abhängig (60 auf Stufe 1, +10/Stufe). Begabungswert wird aus zugeordneten Skills berechnet.

**Lebenspunkte:** Fix **100 LP**. <10 LP bewusstlos, 0 LP Tod. Schaden >60 in einem Treffer = sofort bewusstlos.

**Inspirationspunkte:** Werden durch Vor-/Nachteile, Rollenspiel vergeben. Beeinflussen Würfelergebnisse.

**Inventar:** Freitext, keine Encumbrance.

## Spielmechanik

**Würfel:** W100 (2W10).
**Probenformel:**
```
Wurf <= Skillwert  → Erfolg
Wurf >  Skillwert  → Misserfolg
```
Ohne Skill → Probe gegen Begabungswert.

**Krit/Patzer:** Wurf ≤ Skillwert/10 = Krit; 96–100 = Patzer.

**Schaden (Original):** Pro angefangene 2W10 Würfel = 1 Schaden, min. 10 LP/Treffer.
**Schaden (Universalkampf):**
```
Schaden = (Skillwert − Wurf) / Modifikator   (min. 10)
```

**Stufenaufstieg:** Neue Heldenaktionen/Sprüche, Skill-Cap +10, zusätzliche Skillpunkte.
